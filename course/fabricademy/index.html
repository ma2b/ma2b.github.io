GET STARTED

四步开始对照学习

也可以直接阅读网页笔记
  1. 01

    下载并解压

    下载上方 ZIP，解压得到 fabricademy-learning-panel 文件夹，保存到固定位置。

  2. 02

    加载 Chrome 插件

    在地址栏输入 chrome://extensions/，启用「开发者模式」，选择「加载已解压的扩展程序」，选中刚解压的文件夹。

  3. 03

    打开对应的视频

    从课程卡片点击「在 B站观看」。安装后刷新视频页，再点击浏览器工具栏中的插件图标。

  4. 04

    按章节和时间学习

    在侧栏点章节标题查看笔记，点时间戳定位视频。播放跨章时，正在阅读的内容不会自动跳走。

使用时可能遇到的问题

已经安装过，如何更新插件？

下载并解压新版 ZIP，将程序文件覆盖到原来加载的插件文件夹；到 Chrome 扩展管理页点击「重新加载」，确认 v0.6.5，然后刷新视频页。从 v0.3 升级还需先清除旧 data 和 assets 课程资源目录。v0.6.0 起可在侧栏和提示弹窗顶部查看版本、检查新版及展开更新记录。旧版需先手动升级一次才能获得更新提示；仅点击「更新课程内容」不会更新插件程序。

为什么点击插件，没有打开学习面板？

已匹配课程会打开学习面板；其他页面会显示提示弹窗，附课程主页地址和「重新检查课程」。新识别的课程可以点「打开学习面板」。若提示无法加载，请检查网络后重试。刚安装或更新程序后先刷新 B站页面。切到其他网页时，本插件侧栏会隐藏。

新视频已经上传，旧插件也能直接使用吗？

v0.4.0 起，课程与视频绑定从 GitHub 加载。网站发布新课程后，点击面板中的「更新课程内容」即可；程序功能升级时才需安装新版插件。旧版用户需要先升级一次。

没有插件，或者使用手机，也能学习吗？

可以。点击「阅读课程笔记」即可浏览中文摘要、章节内容与配图，也可单独打开 B站视频。学习面板插件目前面向桌面 Chrome，手机可使用网页笔记和 B站。

插件里的 AI 笔记可以更新吗？

可在面板中点击「更新课程内容」，获取 GitHub 已发布的课程目录和固定 AI 笔记，无需重装插件。首次使用需要联网；读取成功后会缓存文字和时间轴，更新失败保留上次成功内容。图片仍从网站加载，离线时不保证可见。
